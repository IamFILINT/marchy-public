# Marchy — an Arch Linux desktop for the age of agents

Marchy is an independent, rebranded development of the Omarchy desktop experience. It is built on [Arch Linux](https://archlinux.org) and the [Hyprland](https://hyprland.org) compositor, and it is created by [FILINT](https://github.com/IamNOTfilint).

It is a desktop for people who run a coding agent beside them: fast, keyboard-driven, and opinionated about exactly one thing — the choice stays yours.

## The idea

**Okonomi for taste. Okimari for safety.**

- **Okonomi** means "as you like it." Marchy's setup asks what you want and does not pre-select your apps, browser, office suite, AI tools, or desktop style.
- **Okimari** means a fixed course. For people who want a set menu, Marchy offers presets: Nami (minimal), Jo (dev), Tokujo (full), and Hardened.
- **Safety floor** is not a taste choice: firewall, full-disk encryption, signed packages, no passwordless sudo, and no telemetry.

## What is inside

- **Arch Linux base** — a rolling release with `pacman` and the AUR at the centre of everything.
- **Hyprland compositor** — a fast Wayland tiling window manager built for mouse and keyboard.
- **Quickshell shell** — the desktop shell toolkit the bar, widgets, and launcher are drawn with.
- **Agent-friendly by design** — a desktop that assumes a terminal and a coding agent are never far away.

Read [Features and the safety floor](./features/) for the full picture, or [Okonomi and Okimari](./philosophy/okonomi/) for the design rule behind it.
