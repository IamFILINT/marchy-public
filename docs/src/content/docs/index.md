# Marchy — an operating system for the age of agents

Marchy is an independent operating system created by [FILINT](https://github.com/IamFILINT). It is built to be chosen by you, and it assumes a coding agent is running beside you: fast, keyboard-driven, and opinionated about exactly one thing — the choice stays yours.

## The idea

**Okonomi for taste. Okimari for safety.**

- **Okonomi** means "as you like it." Marchy's setup asks what you want and does not pre-select your apps, browser, office suite, AI tools, or desktop style.
- **Okimari** means a fixed course. For people who want a set menu, Marchy offers presets: Nami (minimal), Jo (dev), Tokujo (full), and Hardened.
- **Safety floor** is not a taste choice: firewall, full-disk encryption, signed packages, no passwordless privilege escalation, and no telemetry.

## What is inside

- **A coherent base** — kernel, userland and documentation developed together, with snapshots, boot environments and sandboxes underneath.
- **A fast tiling desktop** — animated, keyboard-driven and scriptable.
- **A shell you can rebuild** — the bar, widgets, launcher and lock screen are yours to change.
- **Agent-friendly by design** — a terminal that is fast to type into and easy to read from a transcript.

Read [Features and the safety floor](./features/) for the full picture, or [Okonomi and Okimari](./philosophy/okonomi/) for the design rule behind it.
